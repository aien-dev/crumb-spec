# Contributing to the Crumb Protocol

The Crumb Protocol is a community-driven, vendor-neutral standard for autonomous software engineering agents. We welcome contributions from developers, researchers, and agent creators worldwide.

## How to Contribute

1. **RFC Proposals**: If you want to propose a new standard field or structural capability, open an Issue titled `RFC: <Your Feature>` detailing the rationale, use case, and proposed JSON schema.
2. **Reference Implementations**: We welcome zero-dependency reference parsers and clients in additional programming languages (Go, Java, C++, Swift, Zig).
3. **Tool Integrations**: Submit documentation or middleware connecting Crumbs to popular frameworks (AutoGen, LangGraph, CrewAI, LlamaIndex, Aider).

## Guidelines

- Maintain absolute simplicity. The core spec must remain fast, human-readable, and dependency-free.
- Adhere to the unslop standard: clear, direct technical language without buzzwords or fluff.
- All contributions are licensed under the repository license (MIT).
